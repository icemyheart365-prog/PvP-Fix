# Security Policy

## Supported Versions

PvP-Fix is currently under active Alpha development.

Security fixes are generally considered for the latest development version of PvP-Fix.

Older development versions may no longer receive security-related fixes.

## Reporting a Vulnerability

If you believe you have discovered a security vulnerability in PvP-Fix, please do not disclose the vulnerability publicly through a GitHub Issue.

Instead, please report the vulnerability privately through the project's available private contact channel.

Please provide as much relevant information as possible, including:

- The affected PvP-Fix version
- Minecraft version
- Server software and version
- Whether Enhanced or Compatibility mode was being used
- Steps required to reproduce the issue
- Expected behavior
- Actual behavior
- Any additional information that may help reproduce or investigate the issue

Please do not include passwords, authentication tokens, personal information, or other sensitive information in your report.

## Public Disclosure

After a security issue has been investigated and, where appropriate, fixed, information about the issue may be disclosed publicly.

The timing and amount of public disclosure may depend on the severity of the issue and whether a fix is available.

## Scope

This policy applies to security vulnerabilities directly related to PvP-Fix.

Issues that are purely related to gameplay behavior, compatibility, performance, or feature requests should normally be reported through the regular GitHub Issue system.
