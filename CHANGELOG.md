# Changelog

All notable changes to PvP-Fix are documented here.

## [0.1.0002-hotfix] - Unreleased

### Fixed
- Repair the existing PvP-Fix 0.1.x implementation.
- Restore the intended behavior of the original 0.1.x features.
- Improve compatibility with Minecraft Java Edition 1.21.11.
- Fix event handling and execution logic that produced no observable gameplay effect in v0.1.0001.

### Notes
- This release is a focused hotfix for the 0.1.x line.
- The original `0.1.0001` release remains preserved as the historical baseline.
- The larger modular architecture is planned for the future 0.2.x development line.

## [0.1.0001] - Initial Release

### Added
- Initial PvP-Fix datapack for Minecraft Java Edition 1.21.11.
- Initial TNT handling.
- Initial fireball handling.
- Initial container cleanup handling.

### Notes
- This version was installed and tested on Minecraft Java Edition 1.21.11.
- The intended gameplay features did not produce observable effects during testing.
- This version is preserved as the original historical baseline and is not modified.
